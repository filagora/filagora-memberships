# Filagora Memberships

Memberships and billing for Filagora: plans with prices in several currencies, member
subscriptions, PayPal checkout and webhooks, free and locally activated plans, and the
entitlement grants a membership brings. Requires
[`filagora/filagora-core`](https://github.com/filagora/filagora-core); it works with
[`filagora/filagora-entitlements`](https://github.com/filagora/filagora-entitlements) and
[`filagora/filagora-forums`](https://github.com/filagora/filagora-forums) when they are installed.

> In progress, unreleased. The package is at `0.1`: the API may change between `0.x` minor
> versions. There is no member-facing frontend: the billing page is yours.
